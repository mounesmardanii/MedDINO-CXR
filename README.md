# MedDINO-CXR

A medical AI project for label-efficient chest X-ray classification using DINOv2.

## Project Goals

- Classify chest X-ray findings
- Compare DINOv2 with a ResNet baseline
- Evaluate performance with limited labelled data
- Add explainability and image retrieval
- Build a reproducible research pipeline

## Current Status

Project environment and repository structure are being prepared.

## Disclaimer

This project is for research and educational purposes only and must not be used for clinical diagnosis.
